# setup instructions

**1. Data Setup**

Go to this link and download the files:
https://drive.google.com/drive/folders/1waLItZbk3o519LJ1QCl5GMYgoFtzO7v5?usp=drive_link

Once downloaded, create a folder named `data` in the backend directory of this project and move all the downloaded files into it.

**2. Frontend**

open a terminal and run:

cd frontend

npm install

npm run dev


**3. Backend**

Open a separate terminal and run the pre-compiled server file from the root directory:

./wikilinks-server
